# Hauteur

窗口层级管理工具:全局快捷键把当前前台窗口放到桌面的指定层级,后台常驻系统托盘。

## 下载使用(免安装,Windows 10/11 x64)

1. 打开 [Releases 页面](https://github.com/ClawbertZuo/Hauteur/releases),下载最新版的 **Hauteur.exe**(约 47MB,自包含单文件,无需安装 .NET 运行时)

   - **国内网络加速下载**(GitHub 直连慢时用):[加速链接](https://gh-proxy.com/https://github.com/ClawbertZuo/Hauteur/releases/latest/download/Hauteur.exe)(第三方代理,可自行选择其他 ghproxy 服务)

2. 双击运行:程序进入系统托盘,启动时 logo 短暂浮现;托盘右键 → 退出
3. 如果浏览器/Windows 提示风险(SmartScreen 拦截):点"更多信息" → "仍要运行"
4. 使用说明:

| 热键 | 动作 |
|---|---|
| `Ctrl+Alt+1` ~ `Ctrl+Alt+5`(可自定义) | 前台窗口设到第 1~5 层(数字 = 从顶部数第几层;1 置顶,2~5 普通带内近似位置;**组内窗口时整组一起设层**) |
| `Ctrl+Alt+T`(可自定义) | 置顶 ↔ 置底(垫底,真正的最后一层)切换(**组内窗口时整组一起切换,视为一个整体层级**) |
| `Ctrl+Alt+G`(可自定义) | 窗口堆叠:按住期间左键点选多个窗口,松开后全部堆叠到第一个点选窗口的位置与大小 |
| `Ctrl+Alt+D`(可自定义) | 撤销前台窗口的层级状态(任意层级,恢复原始 Z 序),并解散其所在窗口组(解绑;`Ctrl+Alt+Del` 被系统保留无法注册) |
| `Ctrl+Alt+滚轮`(修饰键可自定义) | 光标处窗口组翻页:下滚 = 首页移到最后一页,上滚 = 最后一页提到最上 |

所有快捷键均可在设置中自定义,**支持鼠标侧键**(XButton1/2)与 F1~F24(可单独使用,无需修饰键);侧键还可作修饰键组成"**侧键 + 按键**"和弦(按住侧键再按主键)。

被设层级的窗口边缘出现彩色光晕(每层颜色可在设置中自定义),点击窗口不会打乱层级(可在设置中关闭"保持层级");退出程序时自动恢复所有窗口原始层级。

## 功能

- 启动即驻留系统托盘,不弹主窗口;启动时 logo 居中浮现约 1 秒后淡出;单击托盘图标打开设置
- 全局热键把前台窗口设到"从顶部数第 N 层"(默认 **Ctrl+Alt+1~5**,可在设置中自定义):

  | 层级 | 含义 | 实现 |
  |---|---|---|
  | 1 | 置顶(最前) | `HWND_TOPMOST` |
  | 2~5 | 普通带内从顶部数的近似位置(5 不是垫底) | 普通带内按比例插入,**近似值** |

- **Ctrl+Alt+T**(可自定义)**置顶 ↔ 置底**切换:未置顶时按下 = 置顶,已置顶时按下 = 垫底(`HWND_BOTTOM`,真正的最后一层)
- **Ctrl+Alt+G**(可自定义)**窗口堆叠多选**:按住热键进入多选模式(期间左键点击被拦截、不误触应用),左键点选多个窗口——选中窗口显示窗口组颜色的光晕,再次点击取消选中;松开热键后所有选中窗口堆叠到第一个点选窗口(锚点)的位置,大小与锚点一致(可缩放窗口按各自最小/最大尺寸钳制,不可缩放窗口只移动不缩放);**置顶窗口加入堆叠时自动取消置顶**(其层级管理状态一并注销),锚点被提到普通带顶部
- **窗口组绑定**:堆叠后的窗口自动绑定为一组,**拖动其中任意窗口,其余窗口跟随移动、保持相对位置不散开**;组员被关闭自动移出组;组为会话级状态(退出程序即解散),托盘右键菜单"解散窗口组"可手动解绑;**窗口组视为一个整体层级单位**——置顶/设层/垫底操作对整组生效,组内页面顺序保持不变
- **堆叠翻页**:对窗口组**按住修饰键(默认 Ctrl+Alt,可在设置中勾选 Ctrl/Alt/Shift/Win/鼠标侧键)滚动鼠标滚轮**,轮换组内 Z 序——下滚 = 首页移到最后一页(下一页),上滚 = 最后一页提到最上(上一页),重叠的页面像翻书一样切换
- **解绑热键**(默认 `Ctrl+Alt+D`,可自定义):撤销前台窗口的层级状态(任意层级,恢复其原始 Z 序,层级光晕一并移除),并解散其所在窗口组(组内全部成员一并恢复原始层级);未被管理但置顶的窗口则移出置顶带
- **光晕显示**:被设层级的窗口边缘出现渐变光晕(8px 描边,鼠标穿透,紧贴窗口可见边界,圆角与窗口 DWM 圆角严格匹配),跟随窗口移动/缩放/最小化;光晕位于目标窗口自身的 Z 序位置,被更靠前的窗口自然遮挡;**每个层级可单独指定光晕颜色**(默认高饱和紫 #9D00FF → 粉 #FF007F 渐变),所有层级亮度一致、以颜色区分层级,颜色在设置"光晕"页可视化选择(带预览条);**窗口组光晕**为外圈光环(内圈之外 8~16px)、与层级光晕独立并存,颜色同样可在设置中自定义(默认琥珀 #FFB400),多选模式下的选中光晕也使用该颜色
- **层级保持**(默认开启):被设过层级的窗口被点击激活时自动回到设定层级,点击不会打乱层级顺序(可在设置中关闭;仅作用于被 Hauteur 管理过的窗口)
- **退出注销**:程序退出时自动销毁全部光晕,并把所有被调整的窗口恢复到原始层级状态(托盘"退出"、任务管理器结束任务、注销/关机都会触发)
- 设置窗口(标签页:快捷键 / 光晕 / 常规):录制式自定义全部热键(置顶/堆叠/解绑/各层级,支持鼠标侧键与 F1~F24)、光晕双色渐变选择器(带预览)、开机自启、暂停、层级保持开关
- 托盘右键菜单:打开设置 / 恢复所有窗口层级 / 解散窗口组 / 暂停 / 开机自启 / 退出
- 单实例:重复启动会唤起已有实例的设置窗口
- 配置持久化:`%APPDATA%\Hauteur\settings.json`,崩溃日志 `error.log`
- 热键注册冲突、目标窗口提权等异常均以气泡提示,不静默失败

## 构建与发布

需要 .NET 10 SDK:

```powershell
dotnet publish src/Hauteur -c Release
```

产物(自包含单文件,免安装,直接双击运行):

```
src/Hauteur/bin/Release/net10.0-windows/win-x64/publish/Hauteur.exe
```

## 已知限制

- Windows Z 序只有 置底 / 普通 / 置顶 三个带,层级 2~4 是普通带内按比例的近似位置,随桌面可见窗口数量略有浮动
- SPEC 中的光晕显示、右键菜单层级选择尚未实现
- 目标窗口以管理员权限运行时,普通权限的 Hauteur 无法调整其层级(Windows UIPI 限制),需以管理员身份运行 Hauteur
- 无代码签名,SmartScreen / 杀软可能提示
